# Arcanum PI Taxonomy (Jason Haddix / Arcanum Information Security)

## Source Details
- **Type:** Structured threat taxonomy
- **URL:** https://arcanum-sec.github.io/arc_pi_taxonomy/
- **Coverage:** Prompt injection intent, technique, evasion, and input vector classification
- **Confidence:** High

## Key Claims
- Four-axis classification: Intents, Techniques, Evasions, Inputs
- Prompt injection is not just "text input" — any parsed content (external data, encoding tricks, multi-modal) qualifies
- The taxonomy distinguishes between the GOAL of the attack and the METHOD used

## Relevance
Most detailed published prompt injection classification system. Directly useful for building detection rules and understanding attack surface coverage.

## Notable
- Created by Jason Haddix (known Bug Bounty Hunter / security researcher)
- Includes live taxonomy entries that can be browsed by category
