# OWASP GenAI Security Project

## Entity Details
- **Type:** Open-source community project
- **URL:** https://genai.owasp.org/
- **Founded:** 2023
- **Contributors:** 600+ experts from 18+ countries
- **Community Size:** ~8,000 active members

## Role in LLM Threat Modeling
The OWASP GenAI Security Project maintains the authoritative Top 10 vulnerability list for LLM applications (both 2023/24 and 2025 editions). It has grown beyond the Top 10 to include:
- AI Bill of Materials (AIBOM) Generator
- Threat Intelligence resources
- Agentic App Security guidance
- Secure AI Adoption checklist
- AI Red Teaming resources
- Data Security guidelines

## Key Publications
- OWASP Top 10 for LLM Applications (2025 edition)
- OWASP Top 10 for LLM Applications (2023/24 edition)
- LLM01-LLM10 individual risk pages with detailed descriptions, examples, mitigations
- Cheat sheets, whitepapers, tools

## Relevance to This Research
Primary vulnerability taxonomy reference. The 2025 edition reflects updated threat landscape including elevated risks from agentic AI systems.
