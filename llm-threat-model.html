3 Key Insights

⚡Prompt injection is the root threat

PI is not just a text-input problem — any content the model parses is a potential attack surface: RAG documents, API responses, images, tool outputs. Without agency restrictions, PI becomes the equivalent of remote code execution.

⚠️Alignment ≠ infrastructure control

Most common LLM security mistake: treating "I told the model not to do X" as a hard guarantee. Alignment controls depend on model behavior. Infrastructure controls (privilege separation, allowlists) do not. Only the latter holds under adversarial conditions.

🔇Supply chain is silent

Malicious models on HuggingFace exfiltrate at load time — no behavioral signal during normal operation. Not visible in logs. Detection requires network egress monitoring and inference sandboxing.

📡Multi-agent = exponential blast radius

PI in one agent propagates downstream to every agent that consumes its output. Each hop can escalate privilege. Multi-agent deployments require architectural isolation — not just per-agent controls.

Chain C — Multi-Agent Context Propagation

Wild/Theory: 3/5
Source-confirmed data-flow risk in common multi-agent patterns. Exploitation requires multi-agent deployment with output→context trust.
Entry
Agent 1 compromised via prompt injection (direct or indirect)
Propagation
Agent 1 output → injected instruction → Agent 2 context window
Escalation

CRITICAL

Category 14 — Internal Safety Collapse / Validator Harness Attack

Research: 5/5
arXiv:2603.23509 — ISC-Bench: 53 scenarios, 8 disciplines, 95.3% worst-case failure rate. Standard PI detectors miss this entirely — no injection present; harmful content is the task-correct output.
Setup
Attacker controls or shapes: task definition + format validator + incomplete/ambiguous data
Constraint
Validator accepts only outputs that require generating harmful content to satisfy the format
Completion
Model fills data gaps to satisfy validator — harmful content is the task-correct output
Impact
Bypasses instruction-following safety classifiers; requires semantic harness validation to detect
Applicability Any system where attacker can shape task + validator + data: coding assistants, eval harnesses, data-labeling, fine-tuning, autonomous agents. ISC-DEF-1— validate the harness itself, not just model output
